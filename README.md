# iTrade — ESG-Based Stock Recommendation System

A Python-based stock trading assistant that recommends stocks based on ESG (Environmental, Social, Governance) scores.

## Overview

Built as part of the Computational Thinking course at Vrije Universiteit Amsterdam. Grade: 97.5/100.

## Features

- Weighted ESG scoring algorithm for responsible investment filtering
- Implemented and benchmarked Bubble Sort vs Merge Sort on 55,000+ stocks
- Selected Merge Sort for O(n log n) scalability
- OOP architecture with 3 core classes
- Edge-case handling for under-constrained user inputs

## Technologies

- Python
- CSV data processing
- Object-Oriented Programming

## How It Works

1. User inputs investment preferences and ESG priorities
2. System filters stocks based on weighted ESG scores
3. Merge Sort ranks filtered stocks by performance
4. Top recommendations are returned to the user
